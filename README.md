🚀 О проекте

Команда SONDERS разрабатывает интеллектуальную биореакторную систему на основе микроводорослей, предназначенную для поглощения углекислого газа (CO₂), выделения кислорода (O₂) в процессе фотосинтеза и мониторинга параметров работы биореактора.

Наша идея — объединить биотехнологии, цифровые решения и принципы циркулярной экономики, чтобы предложить экологически ориентированное решение для городских пространств, парков и торгово-развлекательных центров.

🌱 Как работает система

1. Поглощение CO₂. Микроводоросли используют углекислый газ для фотосинтеза.
2. Выделение O₂. В процессе фотосинтеза микроводоросли выделяют кислород.
3. Интеллектуальный мониторинг. Датчики помогают отслеживать температуру воды и другие параметры работы биореактора.
4. Управление системой. Smart Dashboard позволяет отображать показатели и контролировать состояние биореактора.
5. Повторное использование биомассы. Избыточные микроводоросли можно собирать для дальнейшей переработки.

⭐ Основные возможности

🌿 1. Биологическая очистка воздуха

Микроводоросли поглощают CO₂ в процессе фотосинтеза. При соответствующих условиях культивирования они могут эффективно накапливать биомассу и связывать углерод.

📊 2. Smart Dashboard

Интеллектуальная панель мониторинга предназначена для отображения параметров биореактора, включая температуру воды и другие показатели, доступные через установленные датчики.

♻️ 3. Переработка биомассы в биотопливо

Одно из перспективных направлений развития проекта — переработка избыточной или отработанной биомассы микроводорослей в биотопливо.

Возможные направления переработки:

- Биогаз: получение горючего газа путём анаэробного сбраживания подходящей биомассы.
- Биодизель: получение топлива из липидов некоторых видов микроводорослей.
- Другие виды биотоплива: выбор технологии зависит от состава биомассы и характеристик сырья.

Такой подход позволяет рассматривать отработанную биомассу не только как отход, но и как потенциальный ресурс для получения энергии.

Производство биотоплива требует дополнительных технологических процессов и оборудования и рассматривается как перспективный этап развития проекта.

🏢 4. Экологические решения для бизнеса

Внедрение биореакторов может стать частью экологических инициатив торговых центров и компаний, способствовать развитию устойчивой инфраструктуры и поддерживать их ESG-цели.

💡 Инновационность проекта

SONDERS объединяет три направления:

- GreenTech — экологические технологии для городской среды.

- Bioenergy — перспективное получение топлива из биомассы микроводорослей.

Главная особенность нашей идеи — стремление объединить биологическую фиксацию углерода, интеллектуальное управление и повторное использование ресурсов в единой системе.
